# 🍎 Apple Sales Analysis

## 📌 Project Overview
This project focuses on analyzing an Apple sales dataset to uncover meaningful business insights and understand the factors influencing iPhone sales and customer preferences.

Using Python and its powerful data analysis and visualization libraries, I explored the dataset to identify sales trends, product performance, customer ratings, and factors that may influence iPhone demand.

## 🛠️ Technologies & Libraries Used
- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computations
- **Plotly** – Interactive data visualization
- **Seaborn** – Statistical data visualization

## 🎯 Key Objectives
- Analyze iPhone sales and product performance.
- Identify which iPhone models perform better.
- Understand factors influencing iPhone sales.
- Explore customer preferences and ratings.
- Discover patterns and trends in the dataset.
- Generate actionable insights from the data.

## 📊 Key Insights
The analysis aims to uncover:
- Best-performing iPhone models.
- Factors that influence iPhone demand.
- Relationship between product features and sales performance.
- Customer preferences and purchasing patterns.
- Trends that can help understand Apple's product performance.
